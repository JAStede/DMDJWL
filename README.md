# DMD JWL — demo website

Luxe demonstratiewebsite voor Diamond Trading B.V. (KvK 93208421).

## Demo bekijken
De website is bedoeld voor Cloudflare Pages. Upload deze map als project (of push naar GitHub en verbind de repository). Cloudflare Pages ondersteunt map-URL’s met `index.html` zonder `.html` in de zichtbare URL.

Voor lokaal bekijken met correcte root-links: voer in deze map `python -m http.server 8000` uit en open `http://localhost:8000/`.

## Nog NIET live als webshop
- Geen werkende betalingen, orders of voorraadadministratie
- Geen live prijzen of bevestigde Emeko-productafbeeldingen
- Formulier is een demo en verstuurt niets
- Juridische documenten zijn concepten
- Afhaallocatie nog te bevestigen
- DMD JWL nog niet als KvK-handelsnaam bevestigd
- `www.dmdjwl.com` is een beoogd domein; configureer pas na domeincontrole
- Logo en afbeeldingen zijn concepten
